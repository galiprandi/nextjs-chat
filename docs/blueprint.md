# **App Name**: NextChat Kids

## Core Features:

- Chat Screen: Make the chat screen easy to see on the /chat page using Next.js 15.
- Easy Chat: Make a simple chat area where you can talk to the computer, using CSS modules.
- AI Helper: Use Vercel's AI tools to help the computer talk back in a way that's easy to understand, using the Deepseek model.
- Smart Talk: Help the computer understand what you say and keep track of how much it talks each day (500,000 words allowed).
- Safe Login: Use Clerk to make sure only you can use your account.

## Style Guidelines:

- Main color: Light and happy, like white or light gray.
- Words color: Dark gray so you can read them easily.
- Fun parts color: Teal (#008080) for buttons and things you can click.
- Easy to read letters that are not too fancy.
- Put everything in a simple place so it's easy to find.
- Make the messages move a little when they show up so it's fun.
